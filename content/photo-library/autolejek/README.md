# Autolejek photo library

Three user-supplied photos saved unchanged for future placement. This library is not included in the published site build. All three photos are also copied to `public/assets/about-project/` and used on the About page in both languages. The dosing-progress photo is the main image. The low-flow-warning, volume-limit, and dosing-progress photos form a swipeable gallery between the use-cases section and the origin story.

- `autolejek-controller-dosing-progress-500l.png` — Controller showing dosing progress: 500 L target, 32 L dispensed, flow 0 L/min.
- `autolejek-controller-low-flow-warning-pl.png` — Controller showing the Polish low-flow warning: check the water supply.
- `autolejek-controller-volume-limit-500l-pl.png` — Controller showing the Polish volume screen: 500 L limit, 0 L dispensed.
